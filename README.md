# sVulnerable
sVulnerable is a way to keep track of security vulnerabilities. 

## What is it? 

sVulnerable is an API that uses data retrieved from [CVE (Common Vulnerabilities and Exposures)](https://www.cve.org/) to create a data pipeline that enterprises can use to keep track of security vulnerabilties that may affect their systems. 

## Why use it? 

It is designed to be light-weight, up to data and intergrates into existing sytems. It is used to be extensible and intergrates into any alerting systems. 

## What is it built in? 

It is built in NodeJS, whilst you can use the pre-population systems that are built into sVulnerable to populate your own datasets, there is also an existing dataset you can query if you need. 

## Philosophy

sVulnerable is designed to scalable, extensible and lightweight. It should be able to intergrate into any system with minimal effort.
